Case Study · Real-Time Personalization

Connecting Oracle Eloqua and Adobe Experience Cloud with Enautics SegmentSync.

Enautics had built middleware to sync Oracle Eloqua segments with Adobe Target and Analytics, but needed its first enterprise deployment. I led the rollout at Mountain America Credit Union, lifting loan application conversion by 37%, and reused the playbook at Anixter and DHL.

Role Technical lead: schema design, audience lifecycle scoring logic, multi-tool sync architecture, and client rollouts

01 — The Context

Bridging marketing automation and on-site personalization

Mountain America Credit Union needed to bridge marketing automation and on-site personalization without forcing returning email subscribers through generic web experiences.

ALIGNMENT

Disconnected email and web channels

Outbound Eloqua email campaigns operated completely separately from Adobe Analytics and Target web experiences.

Siloed systems = fragmented member journey across touchpoints
EXPERIENCE

Known visitors treated as strangers

Subscribers clicking loan rate emails were served generic homepages rather than pre-qualified application funnels.

No recognition = high drop-off on high-intent campaign traffic
VALIDATION

Unproven enterprise middleware

Enautics required an enterprise production deployment in a regulated financial environment to validate SegmentSync's capabilities.

Zero enterprise deployments = needed a proven production reference
02 — The Obstacles

Strict security standards and multi-platform synchronization

Deploying real-time synchronization in financial services meant meeting strict compliance requirements while maintaining sub-second personalization latency.

INTEGRATION

Complex multi-vendor schema mapping

Oracle Eloqua contact fields, Adobe Analytics eVars/events, and Adobe Target profile parameters required bidirectional alignment.

3 distinct platforms = custom schema transformation layer required
COMPLIANCE

Financial services data privacy

Member financial intent and personally identifiable data had to be protected without storing sensitive data in client-side cookies.

Strict compliance = tokenized identification and secure payload handling
MEASUREMENT

Incomplete funnel instrumentation

Existing web analytics lacked step-level telemetry across loan application milestones, preventing precise intent scoring.

Missing telemetry = funnel tracking overhaul required before targeting
03 — The Solution

Closed-loop data architecture and real-time audience orchestration

We instrumented full-funnel tracking, established lifecycle scoring, and configured SegmentSync to stream audience state across Eloqua and Adobe Target.

1
Loan funnel instrumentation audit → step telemetry

Re-architected Adobe Analytics tracking across MACU's loan application steps, capturing interaction depth, rate calculator usage, and drop-off points.Adobe Analytics · Data layer

2
Audience lifecycle scoring model

Defined a 3-tier intent classification model: Aware (content/email browsing), Interested (rate calculations), and Engaged (active application flow).Lifecycle scoring · Taxonomy

3
Real-time SegmentSync deployment Eloqua ↔ SegmentSync ↔ Target

Configured SegmentSync to sync lifecycle states bidirectionally between Oracle Eloqua and Adobe Target within milliseconds of page load.SegmentSync · API sync

4
Dynamic personalization delivery

Built Adobe Target experiences that replaced generic hero modules with contextual loan offers tailored to the visitor's live stage.Adobe Target · Experience delivery
